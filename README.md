## Blessed Living OS

**Blessed Living OS** is my life operating system: one framework that can outfit and upgrade any area of life, built on the **REY Process**. Each project below is a module of that system. Every module is designed, built and shipped by me.

| Module | Area | What it upgrades |
|---|---|---|
| ✝ **[The Path Church App](https://the-path-church.base44.app)** | Ministry | Daily walk with God: verse of the day, daily briefing, Standing in the Gap prayer, Kids Path and missions. |
| ◆ **[REY Process](https://reyprocess.org)** · [source](https://github.com/diversam21-star/reyprocess-site) | Framework | The method behind the system, and its public home at reyprocess.org. |
| ⌂ **[Yard Visualizer](https://github.com/diversam21-star/yard-visualizer)** | Home and yard | Outdoor builds: walk the space, compare ground covers, try structures and plants, see planning-range costs first. |
| ▣ **PathStudio** *(private, in development)* | Studio and organization | Daily order: a command studio for the word, the schedule and the day's priorities. |
| ⚙ **[rey-process-tactical](https://github.com/diversam21-star/rey-process-tactical)** | Navigation | Situational awareness: location, conditions and route planning in one console. |
| ⚙ **[echopaths-sovereign-command](https://github.com/diversam21-star/echopaths-sovereign-command)** · **[blessed-os command](https://github.com/diversam21-star/copy-of-blessed-os-sovereign-command)** | Command | Early Blessed OS command modules, in development. |
